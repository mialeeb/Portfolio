# Mia Biehler — Portfolio

Personal portfolio site: homepage, resume, and case studies.

- `index.html` — the whole site in one file (routes: `#merlin`, `#tiered`, `#agentic`, `#butterfly`, `#resume`)
- `images/` — headshot, homepage previews, and each case study's optimized images (WebP/JPG) and videos (MP4/WebM)
- `files/` — the resume PDF and its page preview

Open `index.html` in a browser to view it locally.
